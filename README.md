
# 👟 Nike App – React + Vite Template

This repository provides a minimal setup to get React working in Vite with Hot Module Replacement (HMR) and some ESLint rules. It's designed to serve as a foundation for building modern web applications with React and Vite.

---

## 🚀 Project Setup

### 1. Clone the Repository

```bash
git clone https://github.com/AryanS-88/nike-app.git
cd nike-app
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

The application will be accessible at [http://localhost:5173](http://localhost:5173).

```plaintext
nike-app/
```
